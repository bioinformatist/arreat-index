# 安全边界

Arreat Index 的功能必须遵守以下固定边界：

- 只读取明确获准的数据，不写入游戏进程；仅在用户执行静态模组应用且游戏停止时写入
  所选安装下 Arreat Index 自有的 `mods/arreat-index` 目录。
- 不注入进程，不使用图形钩子，也不提升权限。
- 不自动执行移动、交易、输入或其他游戏操作。
- 不实现规避检测、隐藏行为或绕过平台与游戏限制的机制。

`arreat-data export` 只读取编译期白名单，拒绝把输出写到游戏根目录下，并对成员大小
和归档路径设限。它不启动游戏或 Battle.net。完整导出和快照只保留在本地忽略路径。

静态模组只读取 Linux `/proc` 进程名，不附加、发信号或杀死进程。它拒绝符号链接、
非目录祖先和无有效 Arreat 所有权清单的已有构建，完整验证暂存输出后才轮换，并在激活
失败时恢复旧构建。输出只含本机 D2R 派生的单个对象 JSON 和两份元数据；仓库与软件包
不携带游戏或社区模组资产。它不启动游戏、修改启动参数或改变任何平台、市场或卖家账户。
