# D2R Affix Data

This context describes how affix property applications retain source facts and gain evidence-backed meanings.

## Language

**Affix Modifier**:
One property application attached to a prefix, suffix, or automatic affix.
_Avoid_: Roll for the entire modifier

**Source Operands**:
The verbatim parameter, Min, and Max cells stored for an Affix Modifier in the game tables.
_Avoid_: Range, because the cells can encode different quantities

**Modifier Interpretation**:
A typed, provenance-backed meaning derived from property metadata while Source Operands remain unchanged.
_Avoid_: Parsed range as a universal term

**Numeric Roll Range**:
Inclusive numeric lower and upper bounds only when property metadata establishes that Min and Max are endpoints.
_Avoid_: Applying it to skill identifiers, trigger chance and level, charges and level, or per-level encodings

**Triggered Skill Effect**:
A chance-to-cast interpretation containing a skill, effective trigger percentage, and skill level. “Proc” is a community synonym.
_Avoid_: Proc as the canonical term

**Charged Skill Effect**:
An interpretation containing a skill, maximum charges, and skill level.

**Item-level Scaled Charged Skill Effect**:
A charged skill whose effective skill level and maximum charges derive from the item's level and the skill's required level while its Source Operands remain unchanged.
_Avoid_: Negative charges, fixed charged skill

**Uninterpreted Modifier**:
An Affix Modifier whose Source Operands are valid but whose property metadata is not yet safely mapped to a typed meaning.
_Avoid_: Invalid modifier

**Evidence Sentinel**:
A named fixture or product evidence assertion reported by audit but not itself a universal data-integrity invariant.

## D2R identity terms

**Era**:
The game patch era used for taxonomy framing. For this project, era is fixed to Reign of the Warlock and is *not* a Market Scope axis.

**Rune**:
One of the named rune goods (`r01` ... `r33`) with fixed identity by number.

**Unique Quality**:
Mainland official wording `暗金` denotes the Unique quality/category and is not one item.

**Set Item**:
One named member of a collectible set, not merely a quality class.

**Fixed-name Item**:
One uniquely identified Unique or Set item while property values may vary.

**Socket Base**:
An unsupported community trade concept usually called `底材`, distinguished by base type, socket count, ethereal/superior state, and other variant details.
_Avoid_: Inferring Socket Base eligibility from an internal `base:*` Canonical Item ID prefix

**Canonical Item ID**:
Project-constructed stable identity generated by Arreat Index from game source identity fields plus localized naming; not an official Blizzard publication artifact.

## Market and price semantics

**Current Ask**:
A posted monetary asking amount for one current listing snapshot.

**Ask Basis**:
What one Current Ask is intended to buy.

**Per-item Ask**:
One rune (`r01` ... `r33`).

**Per-listing Ask**:
The entire eligible fixed-name item listing.

**Comparable Current Ask**:
A non-private current ask for a single canonical target, duplicate-filtered, with positive price values and matching family-basis semantics.

**Current Ask Summary**:
An aggregate observation with sample counts, exclusions, and summary statistics (for example min/median of comparable current asks), storing no title, seller, contact, raw response, or private fields.

**Market Scope**:
The explicit combination of one Season Scope and one Play Mode requested for one current-ask observation.

**Season Scope**:
Whether the Market Scope is non-season or latest season. This is orthogonal to the fixed era.

**Play Mode**:
Whether the Market Scope targets normal or hardcore play. This is orthogonal to D2 difficulty modes and distinct from Normal item quality.

**Market Scope Unavailable**:
A normal market state in which the requested supported Market Scope is absent; this is distinct from malformed or ambiguous provider taxonomy.
